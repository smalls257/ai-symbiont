## Findings that change the build

- **The Glimmer server has one slot** (`parallel = 1` in the router preset), so all Glimmer work runs one call at a time unless the owner allows a config change [measured].
- **Freedoom's text needs layout.** 12 of 40 observations came back as "nothing notable", because the object labels leave out walls, doors and openings. So the game loop adds simple geometry: open space ahead, door left [measured].
- **Each sqlglot image takes about 8 GB of disk.** We'd rather keep one image and check each task out inside it than pull one image per task [hypothesis until the calibration agent verifies].
- **Muse Code has a `--provider local` mode and a `miniswe` preset** [measured: CLI help]. That may be a free path for Glimmer inside Muse Code; we haven't tried it.
- **Muse Code runs an internal "reminder observer" model call** beside the main call [measured: PreLLMCall messages]. It matters for the Wonder comparison, and we haven't looked into it yet.
