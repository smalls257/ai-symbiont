## Findings that change the build

- **Glimmer server is single-slot** (`parallel = 1` in the router preset). All Glimmer work is serial unless the owner allows a config change [measured].
- **Freedoom text needs layout.** 12 of 40 observations were "nothing notable": object labels omit walls, doors and openings. The game loop must add simple geometry (open space ahead, door left) [measured].
- **Disk per sqlglot image is ~8 GB.** Prefer one image with per-task checkout over one image per task [hypothesis until the calibration agent verifies].
- **Muse Code has a `--provider local` mode and a `miniswe` preset** [measured: CLI help]. Possible free path for Glimmer inside Muse Code; untested.
- **Muse Code runs an internal "reminder observer" model call** alongside the main call [measured: PreLLMCall messages]. Relevant to the Wonder comparison; not investigated.
